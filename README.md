# <img src="extension/assets/fucksparx.png" style="width: 2rem"> Sparx Hax
Welcome to **Sparx Hax**, a free browser extension which is designed to assist you with your homework through the use of artificial intelligence.

## How to do it
1. Download the zip file
2. Extract it
3. Group into a file named Sparx-Hax-main
4. Then go to firefox
5. Type about:debugging#/runtime/this-firefox
6. Add this extension https://addons.mozilla.org/en-GB/firefox/addon/sparx-hax/
7. Then press load temporary Add-on (Back on the debug tab)
8. Select the manifest.json file
9. Then go and make a groq account
10. Click on "API keys" on the top then create one
11. Open the extension menu and click on API key
12. Paste your API key (Nothing will happen)
13. Then go back to "Answer" and click solve question!!
14. Congrats!! (If any issues with the code or you dont know how to do it jst DM "breadmanidkbro" on discord

## Disclaimer
This extension uses AI and I can't promise the answers will be correct. Currently AI struggles with certain types of questions, mostly graph questions because it takes what is called a random f***ing guess. If the answer looks messed up, just run the solver again and you will most likely get a different answer. You're just going to have to lock in with graph questions though.

## Installation
This extension is compatible with both Firefox and any Chromium based browser and is available on the Firefox web store: https://addons.mozilla.org/en-US/firefox/addon/sparx-hax/
The packed .crx file and unpacked extension file are both available on this repository for installing on chrome

## Setup 
This extension uses Groq AI, so you'll need to obtain an API key from their website https://console.groq.com/keys. Enter this key into the API key tab of the extension and press save.
